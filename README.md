# Прототип страницы «Провыплаты»

Статический одностраничный прототип для публикации на GitHub Pages. Готовые файлы находятся в `dist/`.

## Локальный просмотр

```sh
python3 -m http.server 4173 --directory dist
```

После запуска открыть `http://localhost:4173/`.

## Публикация

GitHub Pages должен публиковать содержимое ветки `gh-pages`. Исходные материалы аудита находятся в `DESIGN.md`, `CONTENT.md`, `WIREFRAME.md` и `REVIEW.md`.
